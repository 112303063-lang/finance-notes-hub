ABOUT THIS PROJECT

Designed to keep growing.

Finance Notes Hub is a small, beginner-friendly knowledge base built with HTML, CSS, and JavaScript.

Why this website exists

The goal is to make difficult finance concepts easier to review while building a reusable website structure. Each note contains a core idea, key formula or distinction, a simplified example, and practical reminders.

How it stays consistent

The root-level AGENTS.md defines the file structure, design system, editorial format, update checklist, and extension rules. A new note is added to the central data manifest and gets a matching note page. It automatically appears in search and in its category.

Example: adding WACC

The WACC note demonstrates the standard layout: key idea → formula → worked example → reminders. You can find it under Corporate Finance.
